# 料金メモ v1 — 最終構成での原価の再計算と、価格の確定

作成日: 2026-09-05 / 位置づけ: リリース前の価格確定のための計算書。
[`business_direction_v0.md` §3-3](business_direction_v0.md) の「週800 / 月2,000 / 年20,000」は
**軽セッション3分・原価5〜15円/分**を前提にした机上の値だった。実装は1回の授業が
**最長20分**で、TTS も STT も当時と違うものに置き換わっているので、いまの構成で引き直す。

前提にする構成(確定): **STT = Deepgram Nova-3(ストリーミング・日本語モノリンガル)、
LLM = Claude(板書・会話 Haiku 4.5 / 写真解析・復習問題・採点 Sonnet 5)、
TTS = Gemini 3.1 Flash TTS**、WebRTC と agent のホスティング = LiveKit Cloud。

> **実測ではない。** 各社の公開単価(2026-09-05 時点)にコードの構造を当てた見積もりで、
> 会話の長さ・先輩が喋る割合・往復回数は仮定。`voice_metrics`(`agent_speech_seconds` /
> `user_speech_seconds`)と `board_llm_usage` が実データを出しているので、
> 公開後1か月で §2 の表を実測に差し替えること。

## 0. 結論

> **決定(2026-09-05)**: **A** で確定。週 ¥980 / 月 ¥2,980 / 年 ¥29,800(米国 $6.99 / $19.99 / $199.99)。
> Premium の1日上限は **60分のまま**(引き下げは公開後に重い利用者の割合を見てから)。
> App Store Connect の3商品はこの値に更新済み(RevenueCat 経由)。
> なお1回の授業は `FREE/PREMIUM_SESSION_MAX_SECONDS = 1200` で20分が上限
> (`POST /start` が min(1200秒, 残高) を仮押さえ)。原価は分単位なので価格の結論には効かないが、
> 「1回の授業に上限は無いはず」という認識とずれているので、外すなら `PREMIUM_SESSION_MAX_SECONDS`
> を `3600` にする(1行)。

| プラン | **推奨(A)** | 代替(B) | 現状の App Store Connect |
| --- | --- | --- | --- |
| 週 | **¥980** | ¥780 | ¥580 |
| 月 | **¥2,980** | ¥1,980 | ¥1,280 |
| 年 | **¥29,800**(月額比 17% off) | ¥19,800 | ¥12,800 |
| 米国(参考) | $6.99 / $19.99 / $199.99 | $4.99 / $12.99 / $129.99 | $3.99 / $7.99 / $79.99 |

- **A を推す理由**: 標準的な授業1回(12分)の原価が **約¥83**、毎日1回使う人で **月¥2,500**。
  Apple の手数料(Small Business Program 15%)と消費税を除いた手取りは ¥1,980 で ¥1,530、
  ¥2,980 で ¥2,303。**毎日使う人で赤字にならない最低ラインが ¥2,980** で、
  ¥1,980 だと毎日使う人1人あたり月¥1,000 の持ち出しになる(§3)。
- 値下げは後からいつでもできるが、値上げは既存契約者に効かない(Apple は同意が要る)。
  最初は高めに置く。
- **B にするなら、§4 のレバーを先に入れる**(agent の自前ホスト・STT のゲート・
  1日の上限の引き下げ)。それで毎日使う人の原価が ¥1,900〜2,100 まで落ち、
  ¥1,980 の手取り ¥1,530 に近づく(それでも僅かに赤字)。
- 現状の ¥580 / ¥1,280 / ¥12,800 は、**どの利用像でも毎日使う人を賄えない**
  (手取り ¥989 に対して原価 ¥2,500)。据え置く理由が無い。
- 価格と独立に、**Premium の1日上限 `PREMIUM_SECONDS_PER_DAY` を 3,600 → 2,400 秒
  (40分)へ下げる**ことを勧める。上限張り付きの人は月¥11,000 の原価になり(§3)、
  1%いるだけで普通の契約者10人ぶんの粗利が消える。40分でも「毎日、続けて何問も」は嘘にならない
  (12分の授業を3回)。
- App Store Connect の3商品の説明文が「**セッション無制限**」になっている。
  フェアユース上限がある以上これは嘘なので、審査前に直す
  ([`../store/app_store_listing.md`](../store/app_store_listing.md) に差し替え文)。

## 2. 授業1回の原価

コードから読める構造(`backend/agent`・`backend/api`):

- 1回の授業は最長 **1,200秒**(`FREE_SESSION_MAX_SECONDS` = `PREMIUM_SESSION_MAX_SECONDS`)。
- STT は Deepgram へ**在室中ずっと**ストリーミングしている(`voice-session.ts` の `deepgram.STT`。
  先輩が喋っている間のゲートは入っていない)。
- 板書の LLM は `senpai_board.ja.md`(45,003字 ≈ 4万トークン)を system に載せ、
  `cache_control` で毎パス読み直す。1パス = 手順を数件生成して生徒の番になるまで。
- 会話側の LLM(`senpai_conversation.ja.md` ≈ 1万トークン、こちらもキャッシュ)が
  生徒の発話ごとに1回。
- 写真解析(Sonnet 5、画像1〜2枚、出力 ≤1,500)、「わかった」で復習問題を1問(Sonnet 5)、
  復習の回答ごとに採点(Sonnet 5、出力 ≤400)。採点は1問につき 3日後・7日後・不正解なら翌日、で **約3回**。

| 費目 | 仮定 | **標準: 12分** | 上限: 20分 |
| --- | --- | --- | --- |
| STT(Deepgram) | 在室時間ぶん | ¥8.6 | ¥14.4 |
| TTS(Gemini 3.1 Flash) | 先輩の発話 = 在室の45% | ¥24.8 | ¥40.5 |
| LiveKit agent セッション | 在室時間 × $0.01 **(Ship の込み分を超えた場合)** | ¥18.0 | ¥30.0 |
| LiveKit WebRTC | 生徒 + agent の2参加者 | ¥1.8 | ¥3.0 |
| 板書 LLM(Haiku 4.5) | キャッシュ書き 1回 ¥7.5 + パスあたり ¥2.2(読み4万 + 未キャッシュ3千 + 出力1,500) | ¥16.2(4パス) | ¥20.6(6パス) |
| 会話 LLM(Haiku 4.5) | 発話1回 ¥0.4 | ¥3.3(8回) | ¥5.0(12回) |
| 写真解析(Sonnet 5) | 1回 ¥3.6 | ¥3.6(1回) | ¥7.2(2回) |
| 復習問題の生成(Sonnet 5) | 1回 | ¥2.1 | ¥2.1 |
| 採点(Sonnet 5) | 3回 | ¥4.5 | ¥4.5 |
| **合計** | | **¥83(≈¥6.9/分)** | **¥127(≈¥6.4/分)** |

感度:

| 変えるもの | 標準12分への効き |
| --- | --- |
| LiveKit の込み分の内側(月 5,000 agent分 = 標準授業 ≈416回まで) | **−¥18** → ¥65 |
| Deepgram を通常価格で見る | +¥5 |
| TTS を 2.5 Flash TTS にする | **−¥12** |
| 為替 ¥165/$ | +¥8 |

**支配項は TTS(30%)と LiveKit の agent 分(22%)**。LLM は3種合わせても 30% で、
キャッシュが効いている前提の数字。`board_llm_usage` の `cache_read_input_tokens` が
0 のままなら板書 LLM は約 ¥40 に跳ねる(system の 4万トークンを毎パス素で払う)。

## 3. 月あたり: 利用像 × 価格

原価は標準授業 ¥83/回(上限張り付きは 20分 ¥127/回)。

| 利用像 | 回数/月 | 月の原価 |
| --- | --- | --- |
| ライト(週2回・12分) | 8.7 | **¥720** |
| 毎日1回(12分) | 30 | **¥2,490** |
| 毎日2回(15分・¥105/回) | 60 | ¥6,300 |
| 上限張り付き(60分/日 = 20分×3) | 90 | ¥11,400 |
| 無料の最大(20分×毎日) | 30 | ¥3,800 |
| 無料の典型(週2回・12分) | 8.7 | ¥720 |

手取りは **価格 ÷ 1.10(消費税)× 0.85(Apple Small Business Program)**。
SBP に入っていないと 0.70。Google Play も 15%。

| 月額 | 手取り(15%) | 手取り(30%) | 損益分岐(標準授業/月) |
| --- | --- | --- | --- |
| ¥1,280(現状) | ¥989 | ¥815 | 12回 |
| ¥1,980 | ¥1,530 | ¥1,260 | 18回 |
| **¥2,980** | **¥2,303** | ¥1,896 | **28回** |
| ¥3,980 | ¥3,076 | ¥2,533 | 37回 |

| 週額 | 手取り(15%) | テスト週の重い人(15分×5回 = ¥525)との差 |
| --- | --- | --- |
| ¥580(現状) | ¥448 | −¥77 |
| ¥780 | ¥603 | +¥78 |
| **¥980** | **¥757** | **+¥232** |

読み方:

- **平均的な契約者(週2〜3回)はどの価格でも黒字**。¥1,980 で粗利 ¥800、¥2,980 で ¥1,580。
- **毎日使う人は ¥2,980 でようやく黒字(28回 < 30回は僅かに赤字だが、
  LiveKit の込み分の内側なら ¥65/回 → 35回で分岐)**。¥1,980 では月 ¥960 の持ち出し。
- 上限張り付きの人は価格に関係なく赤字。**だから上限を 40分/日に下げる**(¥7,600 → まだ赤字だが半減。
  さらに §4 のレバーで ¥5,000 台)。
- 無料は「毎日20分」で月 ¥3,800。有料の手取りより高い。無料の上限を
  `FREE_SECONDS_PER_DAY` = 900(15分)に下げると ¥2,900、600(10分)で ¥1,950。
  これは転換率との見合いなので、ここでは決めない(公開後の無料→有料の転換率を見てから)。

年額は月額の 10 か月分(17% off)で置く。原価が従量なので年額を深く割る理由が無い
(§3-3 の判断のまま)。年額 ¥29,800 → 手取り ¥23,000/年 = ¥1,919/月 ≈ 毎日使う人で分岐。

## 4. 原価を下げるレバー(価格とは独立に)

| レバー | 効き(標準12分) | 何をするか | いつ |
| --- | --- | --- | --- |
| **agent を自前ホスト** | **−¥18** | Fly.io / Cloud Run 常時起動に載せる([`../deploy-agent.md` §6](../deploy-agent.md))。2GB のコンテナ1台 $30〜60/月で同時数本さばける。LiveKit の WebRTC は Cloud のまま | 月 400 授業(= Ship の込み分)を超えたら |
| **STT のゲート** | −¥4 | 先輩が喋っている間は Deepgram へ流さない(VAD だけ回す)。`pivot_plan_v1.md` §6-1 で計画済み・未実装 | 実装 1〜2日。効きは小さいので後回しでよい |
| 1日の上限を 40分に | 上限張り付きの人を半減 | `wrangler.toml` の `PREMIUM_SECONDS_PER_DAY` を `2400` に | **公開前に** |
| TTS を 2.5 Flash TTS に | −¥12 | `GEMINI_TTS_MODEL` を戻す | 声はキャラクターなので、品質差を聞いてから。3.1 を確定にしたのでここでは採らない |
| 相づち・定型句のプリレンダ | −¥2〜5 | `scripts/generate-prerendered-audio.ts` を広げる | 任意 |
| プロンプトキャッシュの維持 | 板書 LLM が ¥16 → ¥40 に戻らないように | system を安定させたまま保つ(残り時間は `systemTail` に置く、の運用を守る) | 常時 |
