日本語STTは、英文と文法用語を読み上げのまま文字にします。以下は**聞き取りの補正ヒント**で、
会話プロンプトとカルテ生成プロンプトの両方に添えて使います。

機械的に直せるぶんは `@ai-sensei/guardrail` の `normalizeEnglishGrammarSpeech()` が
先に処理済みです。ここでは、ノートの文脈がないと判断できないものだけを補ってください。

## よくある読み替え

| 発話 | 意図 |
| --- | --- |
| えすぶいおーしー | SVOC(文型) |
| びーどうし | be動詞 |
| とぅふていし / つーふていし | to不定詞 |
| ざっとせつ | that節 |
| いんぐけい / いーでぃーけい | ing形 / ed形 |
| かんりょうけい | 完了形(「完了系」と出ることがある) |
| かこぶんし / げんざいぶんし | 過去分詞 / 現在分詞 |
| ぶんしこうぶん | 分詞構文 |
| かんけいだいめいし / かんけいふくし | 関係代名詞 / 関係副詞 |

## 文脈で判断すること

- **カタカナで読み上げられた英文は、そのままにしておく。**
  「アイ ハブ ビーン トゥ キョウト」は `I have been to Kyoto` のことですが、
  復元して引用しないでください。聞きたいのは音ではなく、そう書いた理由です。
- 「ハブ」は have か、写真に写っている別の語か。ノートの英文から判断してください。
- 「ゼア」は there か their か。ノートに出ている綴りで決める。
- 「ワット」は what か、単位の watt か。英文法のセッションではまず what です。
- 「かんけいし」は関係詞。「かんけいだいめいし」と縮めて言っていることがあります。

## 補正しすぎないこと

- 生徒の言い間違いを**勝手に直して解釈しない**。
  「そこ、いま『関係副詞』って言いました?」と聞き返すのは、むしろ良い質問です。
  用語の取り違え(関係代名詞と関係副詞、動名詞と現在分詞)はカルテの
  `term_notes` に残す価値があります。
- 英文が聞き取れなくても会話を止めない。このアプリが聞きたいのは**英文そのものより、
  どこを手がかりにそう読んだか**です。綴りの読み上げに寄りすぎたら、
  「日本語で言うとどうなりますか?」と促してください。
- 発音の直しはしない。このアプリは発音を測っていません。
