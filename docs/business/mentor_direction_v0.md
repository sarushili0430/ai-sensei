# 事業方針メモ — 「AIメンター」路線への回答: シフトではなく完成

作成日: 2026-08-07 / 位置づけ: 事業方針の議論のたたき台(**9/30までの開発スコープは一切変えない**)
前提資料: [`inception-deck.md`](../inception-deck.md)・[`business_direction_v0.md`](business_direction_v0.md)

この文書は「予備校のメンター(質問できる・計画に沿って勉強しているかを指導してくれる存在)を
AIで実現する方向にシフトしてはどうか」という提案への回答。結論から書き、根拠を後ろに置く。

---

## 0. 先に結論

1. **直感には賛成。** 「予備校で一番大事なのはメンター」は正しい観察で、予備校業界自身が
   証明している(武田塾は授業を捨てて管理だけを売って成立した)。授業・解説というコンテンツは
   スタサプ月2,178円とYouTubeで既にコモディティで、家庭が月3〜8万円を払っているのは
   **計画・確認・伴走**のほう。これはインセプションデッキ§1の
   「答えの入手コストはゼロになった」とまったく同じ観察の、継続側の面。
2. **ただし「シフト」ではない。** メンターの業務を分解すると
   (a)計画を立てる (b)実行を確認する (c)つまずきを把握する (d)質問に答える、の4つ。
   カタルテは **(b)と(c)を既に実装している** — 「説明させて確認する」は武田塾の確認テストと
   同型で、カルテは(c)の記録そのもの(名前まで同じ)。欠けているのは(a)計画レイヤーだけ。
   だからこれはピボットではなく、**欠けた1ピースを足すと全体がメンターになる**話。
3. **「質問できる」は2つに割り、半分だけ採る。**
   内容の質問(この問題の解き方)は採らない — 約束1を破る上に、ChatGPTが無料でやる
   最コモディティ領域で、`business_direction_v0.md` §4-1がPDF Q&Aを棄却したのと同じ理由で
   勝ち目がない。**やり方の質問(何をどの順で・どこを復習すべきか)は採る** —
   これはメンターの本業であり、「解答・解説の生成」に当たらない。
   授業をしない武田塾が成立していることが、**答えを教えないメンターが成立する証明**になっている。
4. **キャラは後輩のまま。メンター機能を後輩の物語で実装する。**
   計画=「後輩が教わりたいことリスト」、リマインド=「後輩が待っている」、
   週次振り返り=「今週教わったことの整理」。先生・メンターのキャラを立てた瞬間に
   「答えてくれるはず」という期待を自分から作り、プロテジェ効果も捨てることになる(§4)。
5. **9/30までは何も動かさない。** このメモは `business_direction_v0.md` と同じ扱いで、
   実装判断は10月にH1の数字と一緒に行う。
6. **新仮説 H4(伴走)を立てる**: 「計画と約束の存在は、継続率を上げるか」。
   10月に最小構成で検証できる(§6)。新規開発は計画オブジェクトと通知文言だけで、
   会話・カルテ・間隔反復・課金の資産はすべてそのまま使う。

## 1. 直感の分解 — メンターの何が「一番大事」なのか

予備校の価値構造はこの10年で反転した。コンテンツ(授業)は録画とアプリで限界費用ゼロになり、
残った有料の仕事が「管理」になった:

| プレイヤー | 価格帯 | 売っているもの |
| --- | --- | --- |
| 武田塾・スタディコーチ等(人間の管理) | 月3〜8万円 | 計画(ルート)・宣言・確認テスト・週次面談 |
| スタサプ合格特訓コース | 月約1万円 | 動画+人間コーチの声かけ |
| 河合塾One | 月約4千円 | AIレコメンド+質問(オプション課金) |
| Studyplus | 無料 | 自己申告の学習ログ+SNS |
| ChatGPT(学習モード)・QANDA | 無料〜 | 内容Q&A |

見るべきは2つ。

- **価格の崖**: 月約1万円(人間が入る最低ライン)と月数千円(アプリの上限)の間が
  ぽっかり空いている。空いている理由は「AIの管理は無視してもコストがないから効かない」——
  人間のメンターが機能するのは社会的圧力があるからで、通知を送るだけのAIはそれを持てない。
  この空白への挑戦権が「後輩を待たせる心理コスト」(プロテジェ効果)。うちが既に持っている装置が、
  この市場の一番難しい問題への回答になっている。
- **確認の有無**: Studyplusは「やった」の自己申告ログで、「わかったか」は確認しない。
  武田塾の核は確認テスト(やったと言った範囲を本当にできるか試す)。
  **カタルテは確認テストを「説明」でやるアプリ**であり、この位置を取っているアプリは他にない。

つまりメンター直感は、デッキ§1「答えを配る側は飽和している」の続きとして読める:
**穴を見つける側(実装済み)に、続けさせる側(計画レイヤー)を足せ**、と言っている。

## 2. カタルテ ↔ メンター業務の対応表

| メンターの仕事 | 予備校での実装 | カタルテの現状 |
| --- | --- | --- |
| 計画を立てる | ルート・カリキュラム作成 | **無い(唯一の欠落)** |
| 実行を確認する | 確認テスト | **コア機能そのもの**(説明させる) |
| つまずきを把握する | 面談記録・生徒カルテ | **カルテ**(実装済み・同じ名前) |
| 定着を再確認する | 復習指示 | **間隔反復1/3/7日**(OneSignal実装済み) |
| 毎日の伴走 | LINEの声かけ等 | 連続日数+夜の日課通知(v0 §3-2で構想済み) |
| やり方の質問に答える | 勉強法相談(メンター業務の大半) | 無い(追加余地・§3) |
| 内容を解説する | **武田塾はやらない** | **やらない**(約束1) |

この表の含意: **カタルテは既にメンターの下半身(確認と記録)で、欠けているのは上半身(計画)だけ。**
「メンターAIへのシフト」と呼ぶと別プロダクト作りに聞こえるが、実態は1レイヤーの追加。

## 3. 「質問できる」の線引き

- **解き方・解説 → やらない。** 約束1(デッキ§0)であり、履き違えリスクの議論
  (v0 §3-3「AIは問題を理解していない」)で結論済み。加えて事業的にも、内容Q&Aは
  汎用AIが学習モードを標準搭載し始めた最激戦区で、参入する理由がない。
- **やり方・次の一手 → やる。** 「その穴、◯◯が原因っぽいので、教科書のここを読み直してから
  もう一回説明してください」はカルテと計画を参照した**進め方の指示**であって解説ではない。
  予備校のメンターへの質問も実際には大半がこれ(内容質問は講師と解説書に流れる)。
- **ガードレールは既存の構えを一般化する。** topic_id照合と同じ形で、メンター発話の
  許可範囲を「計画・カルテ・勉強のやり方」に限定し、数学の内容説明に踏み込んだ出力は
  再生成させる。アーキテクチャで約束を守る方針(デッキ§6)はそのまま。
- **滑り坂に注意**: 参考書推薦まで踏み込むと「どの参考書がいいか」のコンテンツ整備
  (=ルート作り)が始まり、v0 §3が全科目対応を退けたのと同じ投資方向の罠に落ちる。
  範囲は「ユーザーの教科書とノート」に留める。

## 4. キャラ問題 — メンターを名乗らせない

「AIメンター」を看板にすると、ChatGPT学習モード・河合塾One・合格特訓と同じ棚に並び、
比較軸が「人間メンターの下位互換」になる。AIメンターの既知の死因は
「無視してもコストがない」で、看板を掛け替えてもこの問題は解けない。

後輩は逆向きに効く。**教える約束を破ることに心理的コストが発生する**(プロテジェ効果の
責任感の側面)。約束4「通知もお願いも後輩の言葉で」が、偶然にもメンター機能の最適な皮になっている:

| メンター機能 | 後輩の物語での実装 |
| --- | --- |
| 計画作成 | 「次のテストいつですか? それまでに、ぼくこれを教わりたいです」(テスト日+単元リスト=計画) |
| 毎日の声かけ | 「今日の分、聞かせてもらえませんか?」(v0 §3-2の日課通知そのもの) |
| 週次面談 | 「今週教わったこと、整理させてください」(週1の振り返りセッション) |
| 遅れの検知 | 「◯◯、早く聞きたいです!」(急かさない。約束3・4) |

**4つの約束との整合(憲法チェック)**:

1. 答えを教えない → 内容Q&Aは採らない(§3)。**維持**
2. 点数を出さない → 計画の進捗は**達成率%にしない**。「教わりたいことリスト」が消えていく
   チェックリスト+既存の連続日数・埋めた穴のみ。**維持(表現に注意が要る)**
3. パスを恥にしない → 計画の遅れを責めない。遅れたら**計画の方を動かす**
   (後輩が「じゃあ先にこっちを聞かせてください」と並べ替える)。**維持(設計で守る)**
4. 煽らない → リマインドは全部お願いの文法。「サボってますね」は書かない。**維持**

つまりメンターレイヤーは憲法改正なしで乗る。危ないのは②の達成率と③の詰問で、
ここを踏むと「管理アプリ」の嫌な顔(監視・叱責)になる。**管理はするが、管理の顔をさせない。**

## 5. 事業面 — 何が強くなるか

- **価格の物語が変わる。** 現状の月2,000円(v0 §3-3)はスタサプと同じ棚で「単科なのに強気」。
  伴走の物語が立つと「人間のメンター月3〜8万円の1/20」の棚に移り、同じ価格の説得力が上がる。
  年額2万円の買い手=親(受験学年)という想定も、「管理を買う」なら親の財布と自然に噛み合う。
- **リテンションの背骨ができる。** 現状はセッション単発の積み重ねで、連続日数以外に
  「やめられない理由」の構造がない。テスト日という締切と「後輩との約束リスト」が入ると、
  数週間単位の継続構造ができる。**H1(継続率)に効く一番太いレバーは多分これ。**
- **原価をほぼ増やさない。** 計画・リマインド・チェックリストはLLMをほぼ使わない
  (テンプレ+カルテ参照)。会話原価の議論(v0 §3-3)を悪化させるのは週次振り返りの
  会話1回分だけ。
- **OneSignal賞の物語が太くなる。** 復習1/3/7+毎晩の日課+週次振り返り、で
  "Keep Them Coming Back" の応募根拠がフルストーリーになる(これは9/30後の話ではなく、
  提出資料の語り方として今から使える)。

## 6. 検証設計 — H4(伴走)

v0のH1〜H3に足す4本目:

| # | 仮説 | 検証手段 | 状態 |
| --- | --- | --- | --- |
| H4(伴走) | 計画と約束の存在は、継続率・再訪率を上げるか | 10月に最小構成: テスト日入力+教わりたい単元リスト+毎晩の呼びかけ+週次振り返り1セッション | 未着手 |

- **最小実装**: planオブジェクト(テスト日・単元リスト・消化状態)+通知文言+
  週次セッションの入口1つ。会話パイプライン・カルテ・間隔反復・課金はすべて既存のまま。
- **測り方の注意**: 「計画を作った人は継続が高い」は自己選択バイアスで汚れる
  (作る人はもともと続く人)。オンボーディングで計画作成への誘導有無を出し分けるなど、
  比較の設計を先に決めてから作る。
- **判定**: 効く → 看板の語り直し(「毎日待ってる後輩」)を検討。
  効かない → 計画レイヤーは畳み、日課通知だけ残す。撤退コストは小さい。

## 7. 北極星(本)との関係 — 路線ではなくレイヤー

v0 §8-1は「教育アプリで勝つか、本ビジョンのPoCか」を問うている。
メンターは**この問いの3つ目の選択肢ではない**。どちらの路線でも使う継続レイヤー:

- 数学版: テスト日と単元リストを後輩と約束する(本メモ)
- 本/PDF版: 「この本を2週間で」と約束し、毎晩「今日はどこまで読みました?」(v0 §4-3の
  「1冊を読み切る」は、そのまま計画レイヤーの本版)

つまり **本=コンテンツ源の拡張、メンター=継続レイヤーの追加**で、直交する。
このメモは§8-1の答えを先取りしない。どちらに進んでも積める投資、というのが採用理由の半分。
