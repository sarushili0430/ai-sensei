## §Q. 確認したいこと(回答をもらってから動きたい順)

### Q-1. アプリ名とリポジトリ名 【§9-8 / 最優先】

§10で「まずアプリ名を確定」とあるので伺います。**カタルテ / セツメイト / ときがたり / 新案** のどれにしますか。

あわせて — 現在のリポジトリ名は **`ai-sensei`(AI先生)** です。本アプリのコンセプトは「AIは教えない、教わる後輩」なので、**名前が思想と真逆を向いています**。Next Genはリポジトリを審査対象として読むので、publicにする前に改名を検討したいです(例: `katarute`)。改名するなら A-06(public化)の前が最も安全です。

### Q-2. アカウントとAPIキーの保有状況 【W1スパイクの前提】

### Q-4. 検証用のノート写真サンプル 【C-07の前提】

### Q-5. Go/No-Goの合格基準を数値で 【8/16のゲート】

§8に「遅延・誤認識が基準未達ならフォールバック」とありますが、**基準の数値が未定**です。8/16に主観で迷うと1週間溶けるので、先に決めたいです。こちらの叩き台:

- 発話終了 → 後輩の応答開始まで **1.5秒以内**(3G相当ではなくWi-Fi/4G前提)
- 数式を含む発話の**意味が通る率 8割以上**(語の完全一致ではなく、Claudeが文脈補正した後の解釈が正しいか)
- 5分の会話で**セッション断が0回**

この基準でよいか、緩めるか厳しくするか。
