説明する数学アプリ(仮称: カタルテ)

写真を撮る → 後輩AIが質問する → 声に出して説明する → 理解の穴が「カルテ」になる。 v0.1 から画面を1枚だけ足し(設定)、行き止まりを全部つぶした版。 MVPのスコープ(handoff §3)は広げていない。

動的コンテンツ(AI生成・ユーザーデータ) UX体験設計の意図 賞審査カテゴリ・収益のフック v1v0.1 からの変更点

v0.1 から変えたこと(と、変えなかったこと)

  1. 遷移を2種類に分けた。 v0.1 の実装はすべての遷移がスタックの置き換え(go)で、 どの画面もスタックの深さが常に1だった。結果、戻るボタンが一度も出ず、 復習画面が行き止まりになっていた。 いまは一方通行(撮影→会話→祝福→カルテ)と寄り道(ホーム⇄復習/設定、⇄ペイウォール)に分け、 寄り道は必ず戻れる。
  2. ホームをハブに戻した。 v0.1 で描いていた「きのうの穴カード」と「今日の無料セッション残り」が 実装で落ちていた。両方戻した(残り回数はサーバが既に返している)。 タブバーは入れない — 常設タブに値するのはホームだけで、カルテはセッション直後にしか 意味を持たない一過性の画面だから。設定は右上に逃がす。
  3. 画面を1枚だけ足した(08 設定)。 新機能ではなく、置き場所の無かったものの集積: 契約の管理・購入の復元・通知・プライバシーポリシー/利用規約・AI出力の報告導線。 後ろ2つは審査で見られる項目で、handoff §5 に自分で書いてあった宿題。
  4. オンボーディングを2ページに。 1枚目は約束(答えは教えません)のまま、2枚目でやることの全体像。 権限は全部「使う直前」に聞く: カメラ=撮る直前 / マイク=会話の直前 / 通知=初回カルテのトグル。v0.1 の 05 に描いてあったトグルは実装では静的テキストだったので、 ここを本物にして、価値を実感した直後に後輩からのお願いとして許可を取る。
  5. Premium の「履歴」を復習画面で果たす。 ペイウォールは「穴の復習と履歴」と謳っているのに 履歴を見る画面が無かった。別画面は作らず、復習画面を 「埋めにいく穴」＋「埋めた穴」の2セクションにした。
  6. 変えていないもの: コアループそのもの、点数を出さない原則、数えるのは連続日数と埋めた穴だけ、 ペイウォールを出す位置(初回カルテ直後・サーバが判断)、無料枠(1日1セッション・最長5分)。

画面遷移

線の種類が、そのまま実装の go / push の使い分けになっている。 実線＝スタックを置き換える一方通行、破線＝スタックに積む寄り道(必ず戻れる)。

一方通行(go・戻れない) 寄り道(push・戻れる) プッシュ通知が起点

画面ごとの遷移の型

画面入り方出口
00 オンボーディング初回起動はじめる → 01(置き換え)
01 ホーム起点撮る / 復習 / 設定 / ペイウォール
02 撮影確認01 から push戻る・説明をはじめる → 03(置き換え)
03 会話02・06 から置き換え今日はここまで → 04。戻るは出さない
04 祝福03 から置き換えカルテ → 05(下にホームが積まれる)
05 カルテ04 から言い直す → 06(push) / 今日はここまで → 01 or 07
06 復習01 から push / 通知から戻る・説明する → 03 / Premiumをみる → 07
07 ペイウォール05・06・01 から閉じる → 来た場所
08 設定01 から push戻る → 01

まだ決めていないこと

  1. 声を出せない場所(電車・自習室)向けに、テキスト入力フォールバックを積むか。
  2. キャラ設計: 名前・一人称・敬語レベル・見た目のトーン。
  3. 「穴」という言葉の強度。刺さるが強すぎる可能性(代案: モヤ、ハテナ)。
  4. 効果音・ハプティクスの方針(Design Award を狙うなら要検討)。
  5. プライバシーポリシー・利用規約・報告先メールの実体(dart_defines.env が空のあいだ、設定画面に行ごと出ない)。提出前に必須。
  6. 英語ロケールの切替。いまは端末のロケール任せで、アプリ内に言語スイッチが無い(日本語端末の審査員に英語を見せる手段が無い)。
