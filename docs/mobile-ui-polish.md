# Mobile UI polish

この文書は、Androidエミュレーターで確認しながら進めるモバイルUI調整の
Draft PRを先に共有するための起点です。実際のUI変更は、レビューしやすい単位で
このPRへ順次追加します。

## 対象

- 主要画面の視覚的な階層、余白、文字組み、色、操作感
- 日本語表示と画面サイズごとのレイアウト
- 余力がある場合は設定画面のUI

## 確認方針

- Androidエミュレーターで主要導線を確認する
- UI変更に応じてgolden testを更新・実行する
- `flutter analyze`、関連テスト、debug APKビルドを通す

基点: `develop` / `fb8c06e`
