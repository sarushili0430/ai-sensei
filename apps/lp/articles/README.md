# apps/lp/articles — 記事の書き方

記事の**正はこのディレクトリの `<slug>.md`** です。
配信されるHTMLは `scripts/build-articles.ts` が焼いた
[`apps/lp/public/articles/`](../public/articles) の中身で、**生成物を手で直しても次の生成で消えます**。

```
apps/lp/articles/
  README.md            この文書(生成の対象外)
  teach-back.md        記事1本 = ファイル1つ。ファイル名がそのままURLになる

apps/lp/public/articles/
  index.html           生成物: 一覧(新しい順)
  teach-back/index.html  生成物: /articles/teach-back/
```

ビルド工程を持たない静的配信なので([`../README.md`](../README.md))、**生成したHTMLもコミットします**。
`pnpm run verify`(とCI)が `--check` で「生成物が `.md` と合っているか」を見るので、
生成し忘れたまま進むことはできません。

## 手順

```bash
# 1. 記事を書く(このディレクトリに <slug>.md を足す)
# 2. HTMLに焼く
pnpm run articles:build

# 3. 手元で見る → http://localhost:8787/articles/
pnpm --filter @ai-sensei/lp dev

# 4. 上げる前の確認(アップロード対象のファイル数を見る)
pnpm --filter @ai-sensei/lp build:check

# 5. .md と生成物をまとめてコミット。公開はいつもの手順
pnpm --filter @ai-sensei/lp deploy:production
```

**`.md` と生成物は同じコミットに入れること。** 片方だけ入れると、CIが `--check` で落ちます。

## ファイル名(= URL)

英小文字・数字・ハイフンだけ。`teach-back.md` → `https://…/articles/teach-back/`。

日本語のファイル名は使えません。URLに入るとパーセント符号化され、
共有されたリンクが読めない文字列になるためです。

## front matter

先頭を `---` で挟んで、`key: value` を1行ずつ。YAMLではないので、入れ子も配列も書けません。

| 項目 | 要否 | 中身 |
| --- | --- | --- |
| `title` | 必須 | 記事の題。60文字まで。`<title>` と `<h1>` と一覧に出る |
| `description` | 必須 | 検索結果とOGPに出る要約。160文字まで(超えると切れる) |
| `date` | 必須 | 公開日 `YYYY-MM-DD`。**一覧の並び順の正** |
| `updated` | 任意 | 改稿日 `YYYY-MM-DD`。中身を直したときだけ入れる |
| `draft` | 任意 | `true` のあいだは生成しない(下書き) |

```md
---
title: わかったつもりは、説明してみるまで気づけない
description: 教わった直後に「じゃあ今の、説明してみて」と聞き返すのはなぜか。
date: 2026-08-20
---
```

## 書ける記法

Markdownの**狭い部分集合**だけを読みます。読めない記法は、黙って本文に素通しせず
**行番号を添えて落とします** —— 公開前のレビューが人の目しかないので、
「書いたつもりの装飾がそのまま文字として出ている」ことに気づけるのはここだけです。

| 書き方 | 出るもの |
| --- | --- |
| `## 見出し` | `<h2>`。飛べるidが自動で付き、3本以上あると目次が出る |
| `### 小見出し` | `<h3>`。`## ` より先には置けない |
| 空行で区切った文 | `<p>`。**段落の中の改行は詰められる**(日本語どうしは空白なし、英語のあいだは空白1つ)。原稿は好きな位置で折り返してよい |
| `- ` で始まる行 | `<ul>` |
| `1. ` で始まる行 | `<ol>` |
| `> ` で始まる行 | `<blockquote>` |
| `**強調**` | `<strong>` |
| `==マーカー==` | 黄色の蛍光マーカー(LPの `.mk` と同じ) |
| `` `文字` `` | `<code>` |
| `[文字](URL)` | リンク。飛べるのは `https://` / `mailto:` / 相対パス / `#見出し` だけ |

**書けないもの**(すべて理由つきで落ちます): `# `、`#### ` 以下、コードブロック、表、画像、
入れ子のリスト、区切り線、生のHTML。
必要になったら記事側で工夫せず、`scripts/build-articles.ts` に足してください。

## 中身の決まり

LPと同じ約束が、そのまま記事にもかかります([`../README.md`](../README.md) / [`../../../README.md`](../../../README.md))。

- **煽らない。** 数字で追い立てない。命令や催促にしない
- **点数の話をしない。** 数えているのは連続日数と埋めた穴の数だけ
- **価格を書かない。** 金額は RevenueCat の Offering から引くので、
  ページに焼くとダッシュボードで変えた瞬間にストアの決済画面と食い違う
- **無いものへのリンクを置かない。** 未公開のURLは、決まってから書く
- **アプリの文言を引くときは `apps/mobile/lib/src/l10n/strings.dart` を正にする**
- **できないことを、できるように書かない。** 対応教科・対応OSは、LP本体の記述より広げない

## 下書きと取り下げ

- 途中まで書いて置いておくなら `draft: true`。生成の対象から外れます
- 公開した記事を取り下げるなら、`.md` を消すか `draft: true` にして `pnpm run articles:build`。
  生成物(`public/articles/<slug>/`)も一緒に片付きます
