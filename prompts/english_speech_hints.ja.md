日本語話者が英語を口に出すとき、STTは**言えている音を落とします**。以下は
聞き取りの補正ヒントで、会話プロンプトとカルテ生成プロンプトの両方に添えて使います。

ここで防ぎたいのは**判定の取り違え**です。冠詞や複数形の -s が文字に出なかっただけで
「言えていない」と判定すると、説明できている生徒に説明し直させることになります。

## 落ちやすい音

| 発話 | 意図 |
| --- | --- |
| アイハブアペン | I have a pen(冠詞は弱く、文字に出ないことがある) |
| ツーブック / ツーブックス | two books(複数形の -s は落ちやすい) |
| ライト | right / light(l と r は文字の上で区別できない) |
| シンク / スィンク | think / sink(th は s・sh に化ける) |
| ハブビーン | have been |
| ユーストゥ | used to |
| ウォントゥ | want to(否定の won't と紛れる) |
| ゼア / ゼアー | there / their / they're |

## 文脈で判断すること

- **冠詞と複数形の脱落は、それだけでは「言えていない」の証拠にしない。**
  説明の対象そのものが冠詞や複数形であるときにだけ聞き返してください。
- 「エー・ビー・シー」のような読み上げは**綴り**です。単語として解釈しないこと。
- カタカナで返ってきた英単語(「コミュニケーション」)は、綴りを問う場面でなければ
  そのまま通してください。
- 「サーティーン」と「サーティ」(13 / 30)、「フィフティーン」と「フィフティ」は
  音が近い。前後の文で判断してください。
- 「〜ing」が「〜イン」になることがあります。進行形か動名詞かの判断は、
  音ではなく文の形から決めてください。

## 補正しすぎないこと

- 生徒の言い間違いを**勝手に直して解釈しない**。
  「いま『has』って言いました?」と聞き返すのは、むしろ良い質問です。
  活用や語の取り違えはカルテの `term_notes` に残す価値があります。
- 発音が聞き取れなくても会話を止めない。このアプリが聞きたいのは**発音ではなく、
  なぜその形を選んだかの説明**です。音の再現に寄りすぎたら、
  「日本語で言うとどうなりますか?」と促してください。
