日本語STTは数式を読み上げのまま文字にします。以下は**聞き取りの補正ヒント**で、
会話プロンプトとカルテ生成プロンプトの両方に添えて使います。

機械的に直せるぶんは `@ai-sensei/guardrail` の `normalizeMathSpeech()` が先に処理済みです。
ここでは、写真の文脈がないと判断できないものだけを補ってください。

## よくある読み替え

| 発話 | 意図 |
| --- | --- |
| にじょう / 2乗 | ^2 |
| るーと / ルート | √ |
| さんぶんのに / 3分の2 | 2/3(**分母が先に来る**) |
| えっくす / わい / ぜっと | x / y / z |
| しーた / ぱい | θ / π |
| いこーる / ぷらす / まいなす | = / + / − |
| だいなり / しょうなり | > / < |
| はんべつしき | 判別式 |
| かっこ〜かっことじ | ( ) |

## 文脈で判断すること

- 「ディー」は、円と直線の文脈では **距離d** か **判別式D** のどちらか。
  写真に写っている式から判断してください。
- 「アール」はほぼ半径r。ただし数列の文脈では公比r。
- 「エヌ」は数列・整数問題では n、確率では試行回数。
- 「かける」が乗算なのか「時間をかける」なのかは、前後の語で判断してください。

## 補正しすぎないこと

- 生徒の言い間違いを**勝手に直して解釈しない**。
  「そこ、いま『解の公式』って言いました?」と聞き返すのは、むしろ良い質問です。
  用語の取り違えはカルテの `term_notes` に残す価値があります。
- 式が聞き取れなくても会話を止めない。このアプリが聞きたいのは**式そのものより、
  手順と理由**です。式の読み上げに寄りすぎたら、「言葉で言うとどうなりますか?」と促してください。
